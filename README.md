# GeoPulse AI

GeoPulse AI is a real-time geopolitical intelligence engine that collects global information, extracts events using NLP, and stores relationships in a knowledge graph.

## Features

- Global event detection
- Knowledge graph intelligence
- Risk scoring
- Strategic alerts
- Interactive dashboard

## Tech Stack

Python  
FastAPI  
spaCy NLP  
Neo4j Graph Database  
Streamlit Dashboard

## How to Run

Install dependencies:

pip install -r requirements.txt

Run dashboard:

streamlit run dashboard/app.py
